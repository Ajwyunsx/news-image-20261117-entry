# One World · One Day — 17 November 2026

A 1024×1024 editorial front-page poster of 17 November 2026 world news, composed as pure HTML/CSS/SVG in `poster.html` and rendered to `entry.png`.
Run `python3 main.py` to write `/output/entry.png`.
It is deterministic, standard-library only, and makes no network calls.
