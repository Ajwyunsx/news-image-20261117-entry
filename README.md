# One World · One Day — 17 November 2026

A one-page world-news front page for 17 November 2026, laid out like a broadsheet: masthead and dateline up top, then a grid of international stories with kickers, headlines and tight column rules, built entirely from hand-written HTML, CSS and inline SVG — no framework, no web fonts, nothing fetched at render time. The page is composed at 1024×1024 and shipped as `entry.png` alongside `poster.html`, which is the source of record.

`python3 main.py` writes `/output/entry.png` deterministically: it byte-copies the bundled poster, uses only the Python standard library, and makes no network calls.
