# One World · One Day — 17 November 2026

A 1024×1024 editorial front-page poster summing up the world news of **Tuesday, 17 November 2026**, composed as pure HTML/CSS/SVG (`poster.html`) and rendered to `entry.png`.

The program writes the image to `/output/entry.png`:

```bash
python3 main.py
```

It is deterministic (a byte-for-byte copy of the shipped PNG), uses only the Python standard library, and needs no network.
